# v3.4 —— 兰大课表

> 这一版在 v3.3 之上加了三件事：**图片上限提到 50 张 + 管理图片（任意删 / 多选删）**、
> **批量导入时自动裁剪**、以及一个**可选的 AI 助手**（说一句话就帮你改课表）。

## 这一版加了什么

**图片：最多 50 张，而且能一张张删了（新）**
以前最多 5 张，而且只有「清除图片」一条路——想删掉第 3 张只能全清重挑。现在：
- 上限提到 **50 张**（组件里始终只显示一张，所以张数不会让桌面变卡）；
- 设置里多了「**管理图片**」：4 列缩略图、带序号，**点一下选中、长按删这一张、可以全选**，
  选好点「删除所选」；删除只影响你选中的那些，其余不动；
- 记录里有、文件却丢了的格子会显示「已丢失」，照样能删掉——正好用来清理坏记录。

**批量导入：不用再一张张裁了（新）**
一次从相册选多张时会问你：**逐张裁剪**（每张都能自己调）还是**自动裁剪**（按图片区的形状
居中裁，一次处理完）。两条路用的是同一套几何算法，所以裁出来的图**比例一致**——
点一下换下一张不会变形。

**AI 助手：说一句话改课表（新，默认关闭）**
主页顶栏多了个「**助手**」按钮（⋮ 菜单里也有「AI 改课表」）。点开之后可以直接说：

> 「这周四按周三的课表上」
> 「下周一停课」
> 「10 月 20 日加一节形势与政策，第 3-4 节」
> 「把周五的英语教室改成天山堂 B202」
> 「以后实验课第 5-6 节，1-16 周，单周」

它会把这些话翻译成调课操作，**先给你看结果**（那一天改前几节 → 改后几节、改后有哪些课），
**你点「应用」才真的改**。改完还能一键**撤销**（回到应用之前的状态）。

几条边界，先说清楚：
- **要用它，得填一个你自己的 API Key**（默认 DeepSeek，也可以在设置里换成别的 OpenAI 格式
  端点）。App **不内置**任何 Key，**不填就一个请求都不发**；Key 只存在这台手机里，
  界面上只显示 `••••` 加末 4 位，日志里不打印。
- **第一次用会先弹一段说明要你同意**，因为这件事和 App 一贯的"没有服务器、不上传数据"不同：
  助手会把「课程名、星期、节次、教室 + 你输入的那句话」**直连**发给你自己配置的服务商。
  发的**不是**学号、姓名、班级、课表链接，也不是登录 Cookie。
- 只支持**当天调课**这类改动（换某天课表 / 停课 / 恢复 / 加一节 / 删一节 / 改一节）以及
  **自己加的课**的增删；「整个学期每周三都停课」这种目前不支持，它会提示你逐日说。
- 费用在**你自己的**服务商账号里产生（App 不代付）；具体价格以服务商官方价格页为准。

## 这一版没变的

- **桌面小组件一行代码都没改**：助手的改动走的是和"点表头调课"完全同一份数据，
  所以课表页、桌面组件、导出图片、上课提醒会一起更新，不会出现"App 里改了、组件没变"。
- 没有服务端、没有广告、没有第三方依赖；权限依旧只有 4 个。

## 安装

下载 `timetable-v3.4.apk` 直接安装。**已装过 v3.3（或更早）的可以直接覆盖安装**，
课表和设置都会保留。

安装时会提示「未知来源」——这是正常的，因为没有走应用商店。

> 装完如果桌面上的小组件看起来还是旧样子：**长按组件改一下尺寸**（或删掉重新加一个），
> 逼启动器重建一次 RemoteViews。App 里「设置 → 其他 → 诊断」有一行 `布局版本=v6-…`，
> 可以用来确认手机上跑的是不是这一版。

## 说明

数据只存在本机。App 本身不上传任何信息、不需要配置服务器；**唯一会联网发送课表内容的是
你自己主动开启的 AI 助手**（发给你自己填的服务商，可随时关掉）。
用到的节日与农历表是内置的，不联网。
