**Release 正文**

```markdown
把兰州大学教务系统的「学生课表」导入安卓，并显示在**桌面小组件**上。

装好 → 登录一次统一身份认证 → 课表自动导入。不需要填任何链接、学号或配置。

## 下载安装

- 下载下面的 **timetable-v3.2.1.apk**（约 2.5 MB）
- 手机点开安装，会提示「未知来源应用」——**这是正常的**，因为没走应用商店
- 装好后：长按桌面空白处 → 小组件 → 找到「兰大课表」→ 拖到桌面
- 首次打开会自动跳到兰州大学统一身份认证，用**兰大 APP 扫码**或**账号密码 + 验证码**登录即可

## 桌面小组件（主要卖点）

- 可上下滑动的课程列表：正在上的课描边高亮，带「还剩 22 分」「明天」「周一」提示
- **正好两整行、永远不会露半行**；行高固定，底部不会切出半截
- 行数可在设置里手动指定（1/2/3/4 行）——针对个别机型（如荣耀）留白过多的情况
- 起止时间 / 教室 / 教师 直接显示在小组件里，不用点开 App

## 课表页

- 自绘网格：今天列胶囊与淡底、当前时刻红线、相邻节次自动合并成「第3-4节」
- 点任意一节课弹出完整信息（课名 / 节次 / 上课时间 / 地点 / 教师 / 周次 / 课序号）
- 单双周、起止周正确过滤；顶部周次可左右切换
- 6 种风格、纯色/相册背景（可调文字蒙版）、周末底色可选、深色模式
- 上课提醒（提前 N 分钟可调）、导出整周课表 PNG

## 它是怎么工作的（也是为什么安全）

- **没有服务器**：所有数据都在你自己手机里，不上传任何地方
- **不接触密码**：登录用的是学校自己的页面（App 内置浏览器打开），账号密码只在学校的页面里流动
- **只开兰大这一个站点**：明文 HTTP 只放行 `jwk.lzu.edu.cn`，其余一律强制 HTTPS
- 请求量很小：每天最多几十次、每次约 30 KB

## 这一版的重点

- **兰大专用**：只服务兰州大学一个站点，入口、解析、明文放行都围绕兰大
- 首次打开直接进兰大登录，一步不多
- 抗改版：课表页路径特征表 + 通用表格兜底解析器（学校页面结构变化时不会整页作废）

## 已知限制

- 教务系统若大改版导致自动导入失效：在网页里自己点到「学生课表」页，用 **⋮ → 导入当前页面** 即可（这条永远有效，并且会记住链接）
- 目前仅 Android；iOS 版是同源移植的源码，尚未编译验证
- 需要 Android 12 及以上
```
