## 二、首次使用（3 步）

### 1. 登录并导入
**装好第一次打开会自动跳到登录页。** 打开的是**兰州大学统一身份认证**，
用 **兰州大学APP扫码** 或 **账号密码 + 验证码** 登录。

登录成功后：App 会在教务系统门户里**自动找到你的「学生课表」入口**，
打开它、抓取、导入，看到「导入成功」就完成了，返回即可。

> 为什么必须"自己找"：课表页长这样 ——
> `…/showTimetable.do?id=<学籍内部号>&yearid=<学年>&termid=<学期>&…`
> 其中 `id` **每个学生都不一样**，`yearid/termid` **每学期都会变**。
> 所以 App 里不可能预先写死任何一条链接（写死了就只有作者自己能用）。
> 登录后 App 会扫描门户页面（含 iframe 框架里的菜单、以及 JS 动态拼出的入口）拿到你自己的那条；
> 万一门户里扫不到，还会退回「不带 id」的链接让教务系统按会话解析你。

> **中途可能闪过「文件未找到 / Tomcat 404」，或出现一次明文跳转，都不用担心** ——
> 那都是教务系统自身的问题：登录跳转 `login.jsp` 根本不存在，而 CAS 票据校验那一步
> 又用了**明文 http**（`http://jwk.lzu.edu.cn/academic/login/lzu/loginLds6Valid.jsp`）。
> App 已针对这两点做了处理：坏链自动改走认证入口；明文只对 `jwk.lzu.edu.cn` 放行
> （其他域名仍强制 HTTPS），否则会报 `ERR_CLEARTEXT_NOT_PERMITTED`。
>
> 登录态由系统 WebView 的 Cookie 保管，App 不保存你的账号密码，也不上传任何数据。

登录页右上角 ⋮ 还有四个备用动作：
**导入当前页面**（手动抓取当前网页）/ **走统一身份认证入口** / **切换桌面版·手机版** / **清空登录状态**。
若哪天自动导入失败，就在网页里手动点到「学生课表」，再点「导入当前页面」。

### 2. 周次（通常不用管）
教务系统课表页里**没有「当前第几周」**这个信息。首次导入时 App 会按学期估算
（秋季学期从 9 月第一个周一算起，春季学期从 2 月 20 日后第一个周一算起），
**大多数同学打开就是对的**。

如果显示不对：**⋮ → 设置 → 周次**，用 `−` / `+` 调成现在实际是第几周，点「应用」。
之后全自动，跨周自动切换。（这是唯一可能需要的设置，一次即可。）

### 3. 放上桌面小组件
回到桌面 → 长按空白处 → **小组件/添加工具** → 找到「兰大课表」→ 拖到桌面。

小组件是一屏能看**两节课**、还能**上下滑动**的列表，右上角一个图标按钮切换两种模式：

**接下来**（默认）—— 正在上 + 接下来要上的，跨天顺延：
```
9月21日 周一
第 7 周 · 接下来 22 节
● 解析几何                      明天
  第1-2节 · 天山堂A408          08:30–10:10
● 计算机基础与C语言            明天
  第7-8节 · 秦岭堂A312          14:30–16:10
```

**整天** —— 今天从早到晚全部课：
```
9月21日 周一
第 7 周 · 今天 3 节
● 高等代数（一）                10:30–12:10
  第3-4节 · 天山堂B307
● 数学分析（一）                14:30–16:10
  第7-8节 · 天山堂A303
● 生物多样性与保护(通识)        19:00–21:35
  第9-11节 · 秦岭堂A304
```

- 右侧**永远显示起止时间**（`08:30–10:10`），不只是开始时间
- **正在上的那节**用强调色描边卡片标出
- 一屏只显示**整行**的课，不会出现被切掉一半的第三节课
- 上下滑动看完整天/后面几天（一次最多 40 条）
- 圆点颜色 = 该课在 App 网格里的配色
- 点右上角**图标按钮**切换模式、点**刷新**立刻拉一次、点列表任意位置打开 App

> 课表数据缓存着就一直能看。**登录过期不会反复提示** —— 只有完全没数据时才会引导登录。

### 3b. 换风格与背景（⋮ → 设置 → 外观）
- **课表风格**：清爽 / 素雅 / 醒目 / 圆润 / 直角 / 极简 —— 点一下立刻切换
- **背景**：默认 / 纯色（8 个预设色）/ 相册图片
  - 选图片后可调「文字蒙版」强度（0–90%），保证字始终看得清
  - 图片按屏宽缩放后纵向平铺，不会只露出一条竖缝

### 3c. 课程显示不全？点一下
手机屏宽 360dp 切成 7 列，每列只剩 40 多 dp —— 长课名不可能全画下。
**点任意一节课**弹出完整信息：课名、节次、上下课时间、地点、教师、周次、课序号。
卡片里放不下的部分自动加省略号，绝不会溢出到相邻格子。
左侧节次列显示**节次 + 开始时间 + 结束时间**三行。

### 3d. 小组件下方一大片空白 / 只显示得下一节课（设置 → 桌面小组件）
有些系统（实测**荣耀 MagicOS** 这一族）回报给小组件的"当前高度"不是真实格子高度，
而是**我们声明的最小高度本身** —— 于是组件明明很高，应用只算得出 1 行课，下面全是空白。

两道保险：
1. **自动**（默认）：应用识别这种"回显"并改用兜底高度，同时声明的最小高度保持在
   **150dp ≈ 2 整行**，即使被回显也稳定给出 2 行；真实格子高度（小米/OPPO/Pixel 报的是真话）
   一律原样采信，100~300dp 都能正确排出整行。
2. **手动**：设置 → 桌面小组件 → 「显示行数」选 **1/2/3/4 行**，桌面立刻按你定的行数重排 ——
   你定几行就显示几行，不再猜。（即使还是放不下，被裁掉的是底部页脚，不是课程。）

> 改完行数如果没变化，把小组件**删掉重新添加**一次：启动器只在添加那一刻读一次尺寸声明。

## 四、出问题了怎么办

**⭕ 优先看「⋮ → 诊断」**，里面有：HTTP 状态、最终 URL、HTML 字节数、
解析出的节次数/课程段数、节次时间表、前 10 段课、页面源码前 3000 字。

自动导入失败时，`logcat` 里的 `LzuTimetable` 标签会打印导航轨迹与课表发现结果
（候选链接数、选中了哪条、注入脚本是否执行），这是排查这类问题的第一手材料。

常见情况：

| 现象 | 原因与处理 |
| --- | --- |
| 登录后提示「没能自动找到课表入口」 | 门户改版了。在网页里手动点到「学生课表」，再点 ⋮ →「导入当前页面」（导入成功后会记住这条链接） |
| 顶部黄条「首次使用：登录一次统一身份认证…」 | 还没导入过 → 走上面的「首次使用 第 1 步」 |
| 顶部黄条「登录已过期…」 | 会话过期（正常，教务系统会踢人）。重登一次即可 |
| 网页显示 `ERR_CLEARTEXT_NOT_PERMITTED` | 已修复（明文只放行 jwk.lzu.edu.cn）。若仍出现，说明教务系统换了新的明文域名，需要把该域名加进 `res/xml/network_security_config.xml` |
| 诊断显示 **HTTP 404** 且最终 URL 是 `login.jsp` | 未登录被挡在门外，重新登录 |
| 诊断显示「解析出 0 门课」 | 教务系统可能改版了。点「导出 HTML」把原始页面导出，
发给我 → 按真实结构改解析器（解析器已内置 rowspan/多段/单双周兜底，改版概率低） |
| 周次显示不对 | 设置 → 周次 → 校正「现在是第几周」 |
| 通知不响 | Android 13+ 需授权通知；另外精确闹钟权限被拒时会自动降级为非精确定时 |

## 五、工作原理

```
首次打开（无任何配置）
   ↓ 加载门户 https://jwk.lzu.edu.cn/academic/ →302→ 统一身份认证
WebView 登录
   ↓ 票据回跳 → 回到门户
   ↓ 注入 JS 扫描门户页：所有 <a>、iframe/frame 内部、整页 HTML 里的 showTimetable 链接
TimetableLink：归一化（补全相对路径、还原 &amp;）→ 打分挑出「学生 · 小节课表」
   ↓ 挑不到 → 退回去掉 id 的兜底链接（教务系统按会话解析当前学生）
   ↓ 导航 → 注入 JS 取 document.documentElement.outerHTML（比二次请求更准）
   ↓ 兜底：HttpURLConnection 带 Cookie 重抓
HTML（GBK 编码）
   ↓ TimetableParser：按 <td id="星期-节次"> 取坐标，不靠表头推列
Course[]（课名/教师/地点/星期/起止节/起止周/单双周）
   ↓ JSON 缓存进 SharedPreferences（含自动发现到的课表链接，供后台刷新用）
   ├─→ 桌面小组件（RemoteViews）
   ├─→ 上课提醒（AlarmManager）
   └─→ App 内网格 / 导出图片（同一个 Canvas 渲染器）
```

**关键设计 1 —— 为什么不硬编码课表链接**：`id` 一人一号、`yearid/termid` 一学期一变，
写死任何一条都等于「只有作者能用」。发现逻辑全部在 `TimetableLink` +
`LoginFlow.DO_DISCOVERY` 里，是纯函数，有完整单测（含 iframe 扫描、诱饵链接打分、
相对路径按门户 origin 补全、哨兵检测）。

**关键设计 1b —— 发现要扫"好几遍"，因为菜单是点开才生成的**（v2.0 的真实翻车点）：

v2.0 只扫一遍门户首页就下结论：扫到 0 条候选 → 退回兜底链接 →
而兜底链接没有 `yearid`，教务系统直接回一张 `<title>提示信息</title> … 学年传递错误 …` 的页面。
用户看到的是"登录成功但一直不出课表"（那份错误页见 `tools/mock/notimetable.u8.html` 的同族现象）。

现在按步骤来（`LoginActivity.runStep`），每步都能命中一种真实形态：

| 步骤 | 动作 | 覆盖的真实形态 |
| --- | --- | --- |
| 1 | 扫当前页 | 首屏 HTML 里就有入口链接 |
| 2 | 等 1.2 秒再扫 | 菜单是 AJAX 填进来的 |
| 3 | 点「信息查询」这类**父菜单** | 树形菜单要点开才生成子项 |
| 4 | 再扫 | 子项「学生课表」已经出现 |
| 5 | 点「学生课表」 | 入口是 JS 跳转、不是 `<a href>` |
| 6 | 再扫 / 收手 | —— |

任何一步点到会跳转的链接，`onPageFinished` 会自己开新一轮（有轮数上限，不会死循环）。
`tools/mock/portal-tree.u8.html` 就是按"菜单要点开才生成、首屏连字面量都没有"造的回归样本。

**关键设计 1c —— 注定失败的请求就不发**：拿不到 `yearid` 时，带着去请求只会换回
「学年传递错误」。所以这种时候 App 不发请求，直接给出可操作的话
（"请在网页里点开「学生课表」，再点 ⋮ →「导入当前页面」"），
上次成功导入过的链接里的 `yearid/termid` 会被继承过来 —— 那种情况才值得一试。
判据是 `TimetableLink.hasYearParam`，有单测。

**关键设计 2 —— 课表页面的单元格**是 `<td id="1-1">`（周一第 1 节），
坐标由 id 直接给出；而**行首 `<th>` 里的标签才是显示用的节次**
（第 5 节的行序是 7，因为中间插了「中午1节/中午2节」）。
显示一律用 `<th>` 标签，定位一律用 id 序号 —— 这两者不可混用。

**关键设计 3 —— 发现脚本不用正则字面量**：注入 JS 写在 Kotlin 原生字符串里，
`\]`、`\\` 这类转义极易写错，而写错就是"整个脚本语法错误 → 静默返回空"，
表现为"永远退化成兜底链接"，极难排查（真实踩过）。现在用 `indexOf` 扫描，
并让脚本回传哨兵值，Kotlin 据此区分"脚本没跑"和"页面里确实没有入口"。

**关键设计 4 —— 小组件行高固定，底部永远不切半行**：

小组件列表的高度必须是「行高」的整数倍，否则底部会露出下一行的上半截
（真机反馈：「第三行露半个」）。这里踩过两次坑：

1. **行高不能在运行时量**。曾经把行样式 inflate 出来"量真实行高"再算列表高度，
   看着严谨，其实错在：量出来的值只对量的时候那段文案成立 ——
   而右侧时间栏在不同数据下是 1~3 行（`正在上` / `明天` / `08:30–10:10`），
   **同一列表里行高本身就不一致**，列表高度取多少都不可能对所有行整除。
2. **`layout_margin` 在 ListView 里会被忽略**（`AbsListView` 会用自己的 LayoutParams
   覆盖列表项），所以行间距不能用 margin 表达，否则每行会多算 2dp。

现在：`widget_today_row.xml` 的外壳固定 `38dp`（= 卡片 36dp + 间距 2dp），
右侧拆成「时间 + 提示」固定两行，`WidgetData.ROW_SLOT_DP` 与布局同源取同一个 38dp，
列表高度 = N × 38dp。自检里 `rowHeights=… uniform=true` 且 `wholeRows` 是整数即达标。

**关键设计 5 —— 出问题要能在手机上直接看到**：`⋮ → 诊断` 里有
**「登录流程轨迹」**（最近 20 步：走到哪一步、扫到几条候选、抓了多少字节、是否登录过）
和 **「桌面小组件」**（系统给了多高、算出来放得下几整行）。
真机问题没法连电脑看 logcat，这两栏就是第一手材料 ——
「学年传递错误」和「行高不一致」都是靠它们定的位。

  学号、班级、学生内部 id、任课教师姓名全部替换为占位值，仅保留页面结构与样式。
- 仓库里不含任何个人信息；打包用的签名密钥与私密素材都被 `.gitignore` 排除在外。

## 七、自己构建

环境：JDK 17 + Android SDK（platform 37 / build-tools 36）；用仓库自带的 wrapper 即可，不必另装 Gradle。

```powershell
$env:JAVA_HOME = "<你的 JDK 17 目录，如 C:\Program Files\Eclipse Adoptium\jdk-17.x.x-hotspot>"
.\gradlew.bat testDebugUnitTest    # 跑单测（472 个）
.\gradlew.bat assembleDebug        # 调试包（含自检广播，仅测试用）
.\gradlew.bat assembleRelease      # 正式包（未配签名时为未签名包）
```

- `local.properties` 里指向 SDK：`sdk.dir=...`（该文件不入库，各自生成本地一份）
- **签名**：`assembleRelease` 会读仓库根目录的 `keystore.properties`
  （`storeFile/storePassword/keyAlias/keyPassword`）。没有它产出未签名包，
  自己签名后再安装即可；换签名会让已安装的旧版无法覆盖升级（Android 会拒绝）。
- AGP 9.x 自带内置 Kotlin，**不要**再应用 `org.jetbrains.kotlin.android`，
  否则会撞 `Cannot add extension with name 'kotlin'`。
- **想在没有真实账号的情况下跑通"登录 → 自动发现 → 导入"全链路**：
  `node tools/mock/server.js tools/mock 8080` 会起一个本地 mock 教务系统，
  用 debug 包把登录入口指到 `http://10.0.2.2:8080/portal.u8.html` 即可
  （仓库里全是**合成**课表与匿名化样本，没有任何真实数据）。

## 八、已知限制

1. **登录态会自动过期**，教务系统的会话本来就会失效 —— 这是设计使然，重登一次即可（约 10 秒）。
2. 周次靠学期 + 日期估算，多数情况正确；**换学期重新导入时会自动重估**（不会覆盖你手动校正过的值），
   拿不准时到设置 → 周次核对一次即可。
3. 通知的准点程度受系统省电策略影响；精确闹钟权限未授予时会退化为非精确（可能差几分钟），
   设置 → 上课提醒里有开启入口。Android 13+ 需要通知权限，打开提醒开关时会申请。
4. 「大节课表」(`sectionType=COMBINE`) 未单独适配 —— 自动发现会优先选 `sectionType=BASE` 的小节课表。
5. 桌面小组件的行数随高度自适应（最多 6 整行，可在设置里手动定死），超出可上下滑动；行高固定 38dp，
   所以**底部不会切出半行**。想显示更多行就把组件拉高（长按 → 调整大小）。
   声明尺寸：`minHeight 150dp`（默认摆放，约 2 整行）+ `minResizeHeight 90dp`（能被缩到多小）——
   **minHeight 必须给够**：少数启动器（实测荣耀）回报的高度就是它，声明 90dp 时会一直按 90dp
   排行，组件高高的却只显示 1 行课（"下方一大片空白"）。
   各家"一格"大小不同（同样 150dp，小米的格子小、按 3 行算，OPPO 按 2 行算），
   所以这个值留了余量；行数实在对不上就用「设置 → 桌面小组件 → 显示行数」手动定死。
   组件很矮时页脚会自动收起（判据是"收掉能不能换来一整行"，不是固定阈值，
   免得出现"高一点反而少一行"的断层）。
6. 解析规则建立在**一份真实页面结构**上（14 节 / 7 天 / 45 段课，已匿名化）。
   若教务系统大改版导致解析为空，走「诊断 → 导出 HTML」反馈即可快速适配。
7. 学校若更换教务系统域名，可在「设置 → 课表来源 → 登录入口（高级）」里改，
   自动发现与兜底链接都会跟随该入口的域名。
